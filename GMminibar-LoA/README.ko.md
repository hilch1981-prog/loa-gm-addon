# GM MINI BAR[판다리아-LoA]

와우5.4.8(18414),Interface 50400,Lua 5.1. 공개 배포1.0.0입니다.

이 `GMminibar-LoA` 폴더 하나를 `Interface/AddOns`에 넣습니다. 폴더명과 `GMminibar-LoA.toc`를 유지하고 애드온 목록에서 켠 뒤 `/gmbar`를 입력합니다. `WTF`를 보존하면 `GMMPandariaDB`의 기존 설정을 유지할 수 있습니다. 서버 코어에 맞는 미니바 하나만 활성화하세요.

14슬롯·GM 도구·목록 검색·퀘스트/전문기술·은행/기본 가방 연결을 포함합니다. 서버 GM 권한이 필요합니다. 전체 명령·착지·다른 언어·파티 기능의 실제 게임 확인은 미완료입니다.

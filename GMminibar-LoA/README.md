# GM MINI BAR — Pandaria / LoA

WoW 5.4.8(18414),Interface 50400,Lua 5.1. Public release1.0.0.

Place this single `GMminibar-LoA` folder in `Interface/AddOns`,keeping its name and `GMminibar-LoA.toc`. Enable GM MINI BAR[Pandaria-LoA] and enter `/gmbar`. Preserve WTF for `GMMPandariaDB` settings. Use only the core edition matching your server.

14 minibar slots,GM utilities,catalog search,quest/profession tools,bank/client-bag routing. Server commands require the appropriate GM permissions. Catalog coverage and a sent command are not proof of successful gameplay.
